# Snow Escape — Vite / Three.js

Refactor modular del juego `yetiAstra.html`, con modelos y sonidos procedurales.

## Ejecutar

Requiere Node.js 20.19+ o 22.12+ y npm. Desde la carpeta del proyecto:

```bash
npm install
npm run dev
```

Abre la URL que imprime Vite. Para móvil en la misma red utiliza la dirección de red impresa por Vite; permite el puerto en el firewall. No abras `index.html` directamente con `file://`.

```bash
npm test
npm run build
npm run preview
```

`dist/` es el resultado publicable. `base: './'` permite alojamiento estático en una subcarpeta. Three.js se instala y empaqueta: no se importa desde CDN en ejecución. La instalación sí requiere acceso al registro npm. No hay GLTF, texturas ni archivos de audio remotos. Después de la primera instalación conserva `package-lock.json` en el repositorio y utiliza `npm ci` en CI.

## Controles

- ←/→ o A/D: girar.
- ↑ o W: freno en cuña.
- ↓ o S: posición de descenso.
- F o Shift: turbo.
- Espacio/P: pausa; R: reinicia; Enter: iniciar desde menú.
- F2 o tecla de acento grave: diagnóstico, troncos y rocas visibles.
- Móvil: cuatro botones Pointer Events con multitouch y captura de punteros.

Clásico: turbo sin consumo de energía. Moderno: 6 s de consumo y 8 s de recarga nominal. Las velocidades se suavizan y los giros reducen la velocidad. Aparición inicial del Yeti seleccionable: 500/1000/2000 m. Tras escapar, el siguiente encuentro comienza 600 m después de desaparecer el Yeti.

### Rendimiento y precisión

- Simulación fija a 60 Hz, máximo seis pasos por frame y delta limitado a 100 ms. Se descarta exceso de tiempo para evitar una espiral de recuperación. A FPS muy bajos la partida puede avanzar más lentamente que el reloj real; es una decisión explícita.
- Floating origin: la distancia absoluta se conserva en CPU, mientras la escena se representa alrededor del esquiador. Evita degradación de precisión GPU en descensos largos.
- Ocho bloques de seis filas: hasta **1.056 árboles** lógicos, dibujados con cinco capas instanciadas. Las rocas tienen un pool independiente. Las matrices de obstáculos solo se reconstruyen al reciclar un bloque.
- Frustum culling activado en terreno y obstáculos. Cada InstancedMesh dispone de una esfera local conservadora, independiente del desplazamiento del origen. No se usa una única malla gigante que fuerce a dibujar toda la montaña.
- Partículas: 650 posiciones/colores persistentes. Estelas: 720 instancias. Culling desactivado solo en estos dos pools móviles, de extensión acotada.
- Física, entradas y efectos evitan arrays, objetos y vectores temporales por tick. Esto **no significa cero GC de todo el navegador**: Three.js, DOM, strings del HUD, escritura de récords y nodos Web Audio de eventos pueden asignar memoria. La regeneración calcula normales de terreno y también puede tener asignaciones internas de Three.js.
- Sombras PBR y DPR limitado. Calidad automática reduce DPR si cae por debajo de 47 FPS y desactiva sombras bajo 36 FPS. Alta conserva sombras; Ligera las desactiva desde el inicio.
- Los 60 FPS son un objetivo, no una garantía para todas las GPU, resoluciones o navegadores. No se han medido FPS en este entorno de entrega.
- La AABB expandida de las rocas es una aproximación conservadora: puede detectar contacto en las esquinas antes que un test círculo-vs-caja exacto. Los troncos se prueban como cilindros en el plano XZ; la pendiente se muestrea para la altura visual.
- Los cuerpos y rocas no vuelan en la simulación: la altura Y es visual. Durante protección temporal el Yeti no puede capturar al jugador.

### Entrada cinematográfica y audio

La posición de aparición se proyecta a NDC y se desproyecta desde `y=1.25`, ligeramente por encima del borde superior. Una curva smoothstep la lleva a la nieve detrás del jugador. El listener sigue la posición/orientación de la cámara, y el PannerNode del Yeti sigue su posición renderizada, incluida la entrada. El viento es una cama estéreo no espacial. El audio requiere el gesto de iniciar o activar sonido; si Web Audio no está disponible, la partida continúa en silencio.

### Diagnóstico y pruebas

`window.SnowEscape.getDiagnostics()` devuelve estado, semilla, FPS estimados, distancia, draw calls y calidad. `window.SnowEscape.validateWorld()` comprueba el margen del corredor.

`npm test` comprueba CCD, broad phase, determinismo, pooling, corredor para 100 semillas/10 km y almacenamiento. No sustituye pruebas de integración WebGL.

Checklist manual:

1. Probar ambos modos y las tres distancias iniciales.
2. Mantener turbo en moderno hasta agotar energía; soltar y verificar recarga.
3. Invocar al Yeti desde debug; observar entrada superior, tropiezo y captura.
4. Escapar con turbo; comprobar nuevo encuentro y radar.
5. Pausar, cambiar de pestaña y soltar punteros fuera de los botones.
6. Usar dos dedos; probar rotación del móvil y resize en pausa.
7. Comparar Alta/Ligera/Auto en escritorio y móvil reales.
8. En DevTools Performance/Memory registrar varias bajadas y revisar heap, pausas GC, draw calls y percentiles de frame time, no solo FPS medios.
9. Simular pérdida de contexto con `WEBGL_lose_context`; la UI solicita recarga.
10. Ejecutar `npm run build` y servir `dist/` mediante HTTP.

import * as THREE from 'three';
export class AudioManager {
  constructor(storage){this.storage=storage;this.enabled=storage.get('audio','true')!=='false';this.ctx=null;this.forward=new THREE.Vector3();this.up=new THREE.Vector3();this.events=new Set();}
  init(){
    if(this.ctx){this.ctx.resume().catch(()=>{});return;}
    const AC=window.AudioContext||window.webkitAudioContext;if(!AC)return;
    try{
      this.ctx=new AC();const c=this.ctx;this.master=c.createGain();this.master.gain.value=this.enabled?.45:0;this.master.connect(c.destination);
      const buffer=c.createBuffer(1,c.sampleRate*2,c.sampleRate),data=buffer.getChannelData(0);for(let i=0;i<data.length;i++)data[i]=Math.random()*2-1;this.noiseBuffer=buffer;
      this.source=c.createBufferSource();this.source.buffer=buffer;this.source.loop=true;
      this.windFilter=c.createBiquadFilter();this.windFilter.type='lowpass';this.windFilter.frequency.value=650;this.windGain=c.createGain();this.windGain.gain.value=0;
      this.source.connect(this.windFilter);this.windFilter.connect(this.windGain);this.windGain.connect(this.master);
      this.cutFilter=c.createBiquadFilter();this.cutFilter.type='bandpass';this.cutFilter.frequency.value=1800;this.cutFilter.Q.value=.8;this.cutGain=c.createGain();this.cutGain.gain.value=0;
      this.source.connect(this.cutFilter);this.cutFilter.connect(this.cutGain);this.cutGain.connect(this.master);
      this.yetiPanner=c.createPanner();this.yetiPanner.panningModel='HRTF';this.yetiPanner.distanceModel='inverse';this.yetiPanner.refDistance=10;this.yetiPanner.maxDistance=300;this.yetiPanner.rolloffFactor=.8;this.yetiPanner.connect(this.master);
      this.source.start();c.resume().catch(()=>{});
    }catch{if(this.ctx)this.ctx.close().catch(()=>{});this.ctx=null;}
  }
  toggle(){this.enabled=!this.enabled;this.storage.set('audio',this.enabled);this.init();if(this.ctx)this.master.gain.setTargetAtTime(this.enabled?.45:0,this.ctx.currentTime,.04);}

  }

import { clamp } from '../config.js';
// Segment against a Minkowski-expanded cylinder (XZ disk). No temporary vectors.
export function segmentCircle(x0,d0,x1,d1,x,d,radius){
  const vx=x1-x0,vd=d1-d0,l=vx*vx+vd*vd;
  const t=l?clamp(((x-x0)*vx+(d-d0)*vd)/l,0,1):0;
  const dx=x0+vx*t-x,dz=d0+vd*t-d;return dx*dx+dz*dz<=radius*radius;
}
// Slab test: conservative circle-vs-rock AABB sweep. Expansion includes body radius.
export function segmentAABB(x0,d0,x1,d1,minX,maxX,minD,maxD,radius=0){
  let lo=0,hi=1;const vx=x1-x0,vd=d1-d0;
  minX-=radius;maxX+=radius;minD-=radius;maxD+=radius;
  if(Math.abs(vx)<1e-10){if(x0<minX||x0>maxX)return false;}
  else {let a=(minX-x0)/vx,b=(maxX-x0)/vx;if(a>b){const t=a;a=b;b=t;}lo=Math.max(lo,a);hi=Math.min(hi,b);if(lo>hi)return false;}
  if(Math.abs(vd)<1e-10){if(d0<minD||d0>maxD)return false;}
  else {let a=(minD-d0)/vd,b=(maxD-d0)/vd;if(a>b){const t=a;a=b;b=t;}lo=Math.max(lo,a);hi=Math.min(hi,b);if(lo>hi)return false;}
  return lo<=hi;
}
export class CollisionSystem {
  constructor(world){this.world=world;this.candidates=0;}
  hit(x0,d0,x1,d1,radius,treesOnly=false,ignoreId=-1){
    const low=Math.min(d0,d1)-radius-2,high=Math.max(d0,d1)+radius+2;
    this.candidates=0;
    for(let bi=0;bi<this.world.blocks.length;bi++){
      const block=this.world.blocks[bi];if(block.end+8<low||block.start-8>high)continue;
      for(let i=0;i<block.items.length;i++){
        const o=block.items[i];if(!o.active||o.id===ignoreId||(treesOnly&&o.type!=='tree')||o.d+o.r<low||o.d-o.r>high)continue;
        this.candidates++;
        if(o.type==='tree'?segmentCircle(x0,d0,x1,d1,o.x,o.d,radius+o.r):segmentAABB(x0,d0,x1,d1,o.x-o.r,o.x+o.r,o.d-o.r,o.d+o.r,radius))return o;
      }
    }return null;
  }
}

import { CONFIG as C, corridor } from '../config.js';
export class WorldGenerator {
  constructor(){
    this.blocks=[];this.randState=1;this.nextStart=0;this.nextId=0;
    for(let b=0;b<C.blockCount;b++){
      const block={start:0,end:0,revision:0,items:[],flags:[]};
      for(let i=0;i<C.rowsPerBlock*22;i++)block.items.push({active:false,id:0,type:'tree',x:0,d:0,s:1,r:1});
      for(let i=0;i<C.rowsPerBlock;i++)block.flags.push({active:false,x:0,d:0,blue:false});
      this.blocks.push(block);
    }
  }
  random(){let t=this.randState+=0x6D2B79F5;t=Math.imul(t^t>>>15,t|1);t^=t+Math.imul(t^t>>>7,t|61);return ((t^t>>>14)>>>0)/4294967296;}
  assign(o,type,x,d,s){o.active=true;o.id=this.nextId++;o.type=type;o.x=x;o.d=d;o.s=s;o.r=type==='tree'?.38*s:s;}
  fill(block,start){
    block.start=start;block.end=start+(C.rowsPerBlock-1)*C.rowStep;block.revision++;
    for(let i=0;i<block.items.length;i++)block.items[i].active=false;
    let index=0;
    for(let row=0;row<C.rowsPerBlock;row++){
      const d=start+row*C.rowStep;
      for(let side=-1;side<=1;side+=2)for(let j=0;j<9;j++){
        this.assign(block.items[index++],'tree',side*(C.halfWidth+.9+(j%3)*3.2)+this.random()*1.8,
          d+(Math.floor(j/3)-1)*4.3+this.random()*1.5,.8+this.random()*.45);
      }
      for(let j=0;j<4;j++){
        const x=-22+this.random()*44,od=d+(this.random()-.5)*6,s=.7+this.random()*.45,type=this.random()<.76?'tree':'rock';
        if(Math.abs(x-corridor(od))>C.safeHalf+1.8*s)this.assign(block.items[index++],type,x,od,s);
      }
      const f=block.flags[row],n=Math.round(d/C.rowStep);
      f.active=d>20&&n%3===0;f.x=corridor(d);f.d=d;f.blue=n%2===0;
    }
  }
  reset(seed){this.randState=seed>>>0;this.nextId=0;this.nextStart=-C.rowsPerBlock*C.rowStep;
    for(let i=0;i<this.blocks.length;i++){this.fill(this.blocks[i],this.nextStart);this.nextStart+=C.rowsPerBlock*C.rowStep;}}
  update(distance){for(let i=0;i<this.blocks.length;i++)if(this.blocks[i].end+8<distance-78){this.fill(this.blocks[i],this.nextStart);this.nextStart+=C.rowsPerBlock*C.rowStep;}}
  validate(){
    for(let b=0;b<this.blocks.length;b++)for(let i=0;i<this.blocks[b].items.length;i++){
      const o=this.blocks[b].items[i];if(o.active&&Math.abs(o.x)<C.halfWidth&&Math.abs(o.x-corridor(o.d))<=C.safeHalf+o.r+.39)return false;
    }return true;
  }
}
